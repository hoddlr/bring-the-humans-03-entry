already published on TikTok; this entry links to it via `VIDEO.json`.

## Run

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` byte-for-byte into the output directory.
